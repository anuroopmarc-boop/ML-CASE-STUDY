# ML Case Study — 23CSE301

**B.Tech CSE III Year | Academic Year 2026-27 | Machine Learning Capstone**

A Streamlit web application that demonstrates two ML tasks:

## 🚗 Task 1 — Used Car Price Prediction (Regression)
- **Model:** Gradient Boosting Regressor
- **Dataset:** ~99,000 UK used car listings
- **Input:** Make, Model, Year, Mileage, Transmission, Fuel Type, Engine Size, Tax, MPG
- **Output:** Predicted market price (£)

## 📈 Task 2 — Employee Promotion Prediction (Classification)
- **Model:** Random Forest Classifier
- **Dataset:** ~54,000 HR records
- **Input:** Department, Region, Education, Gender, Training history, Performance ratings
- **Output:** Promotion probability (%)

## 📊 Task 3 — Clustering (Marketing)
- K-Means + Agglomerative Hierarchical Clustering on marketing campaign data

## Tech Stack
- Python 3.11 · Scikit-learn 1.x · Streamlit · Plotly · Pandas · NumPy
